# 控制基础：PID、角度单位、Gazebo 与 MuJoCo 的差异

SO-101 仿真调试中涉及的三个基础主题。原理讲解全部使用本仓库机器人的真实参数。

## 1. PID 控制

### 1.1 公式与三项直觉

PID 每周期根据误差 `e = 目标 − 当前` 算输出力矩：

```
τ = kp·e + ki·∫e·dt + kd·de/dt
     P项      I项        D项
```

| 项 | 直觉 | 视角 | 作用 |
|---|---|---|---|
| P 比例 | **弹簧**：差得越远拉得越狠 | 现在差多少 | 刚度/响应速度的主宰 |
| I 积分 | **记账本**：误差赖着不走，力就一直涨 | 过去累计差多少 | 消灭 P 留下的静差 |
| D 微分 | **刹车**：误差变化越快越用力压 | 变化趋势 | 防冲过头、抑振荡 |

一句话分工：**P 决定快不快，D 决定稳不稳，I 决定准不准**。

### 1.2 静差（steady-state error）

系统静止后仍残留的位置偏差。根源：P 的力来自误差，误差归零力也归零——要产生固定对抗重力的力，就必须保留固定误差：

```
静差 = 重力矩 ÷ kp
```

例：肩关节重力矩约 0.4 N·m。kp=998 时静差 4e-4 rad（0.023°，看不见）；kp=10 时静差 0.04 rad（约 4°，一眼可见）。消除办法：加大 kp（有振荡上限）或加 I 项。

### 1.3 积分项详解

离散实现就是每周期一次加法：`累积量 += 误差 × 周期`，`I 项力矩 = ki × 累积量`。

误差 0.010 不动、ki=50、周期 0.01s 时的累积过程：

| 时间 | I 项力矩 | 含义 |
|---|---|---|
| 0.1s | 0.05 | 开始出力 |
| 1s | 0.5 | 每秒涨 0.5，持续推回目标 |
| 2s | 1.0 | 足够消掉静差 |

关节回零后误差清零，账本停止增长。I 的风险是**积分饱和（windup）**：输出已顶到执行器上限时账本还在涨，工况突变会把积累的力猛地释放 → 超调、震荡。对策：`max_integral_error`（账本上限）、`antiwindup`（饱和时暂停记账）。

### 1.4 本项目中的真实参数对照

| 出处 | 值 | 解读 |
|---|---|---|
| MuJoCo `sts3215` 类 | kp=998.22, kv=2.731, forcerange=±2.94 | 官方按真机标定的等效舵机伺服：极硬弹簧 + 适中阻尼，力矩硬限幅对应 STS3215 堵转力矩 |
| MuJoCo 默认关节参数 | damping=0.60, frictionloss=0.052, armature=0.028 | 关节黏滞摩擦 / 干摩擦 / 电机转子惯量（URDF 格式不支持这些属性） |
| Gazebo 实验（已证伪） | pos_kp=50, kd=1 @ 100Hz | 剧烈振荡；100Hz 下稳定上限 kp≈6 |
| Gazebo 默认 | 无 PID 参数 | 不走 PID，走 SetPosition 传送模式（见第 3 节） |

### 1.5 调参口诀

1. 先调 P：加到"能快速跟上但轻微振荡"为止
2. 再加 D：消振荡、压超调；出现高频抖动就减
3. 最后调 I：静差不可接受才加，配合限幅
4. 目标不同参数不同："保持位置 / 跟踪轨迹 / 抵抗外力"是三组值

## 2. 角度单位：弧度与度

- **ROS 话题、URDF、MJCF 里的数值全部是 rad**（`angle="radian"`）；`°` 只是给人看的直观单位
- 换算：`1 rad ≈ 57.3°`，`1° ≈ 0.0175 rad`
- 对旋转关节，JointState 的 `position` 就是转角（rad），`velocity` 是角速度（rad/s）；平移关节才是位移（m）
- 零点无绝对含义：position=0 是 URDF/CAD 定义的零位（`elbow_flex` 还带 5° 标定偏移），绝对位姿靠 TF 链乘出来

## 3. Gazebo 与 MuJoCo 的本质区别

不是材质差异。同一机器人模型的行为差异来自三层"看不见的设定"：

### 3.1 关节驱动的实现（最主要）

| | Gazebo（默认） | MuJoCo |
|---|---|---|
| position 指令的执行 | `SetPosition` **传送**：每步把关节直接摆到目标，跳过重力和动力学 | **位置伺服**：`τ = kp(q目标−q) − kv·q̇` 每物理步算力矩，和重力对抗着走过去 |
| 结果 | 零下垂零超调，但物理上"假"：夹爪遇物体会穿透，没有力交互 | 有真实手感：过冲、回稳、受力让位，和真机一致 |
| 参数 | 传送模式不算力，PID 参数无处安放 | 需要 kp/kv/forcerange 这组伺服参数 |

### 3.2 关节自身的物理建模

MJCF 每个关节带 damping / frictionloss / armature（真实舵机特性）；Gazebo 的 URDF 关节是理想无摩擦铰链（格式不支持这些属性）。

### 3.3 数值积分方式（决定参数能否复用）

- **MuJoCo**：隐式积分 + 约束求解器，kp=998 无条件稳定
- **Gazebo（ODE）**：显式积分，控制回路力矩每 dt 才更新一次，稳定判据 `kp < 4J/dt²`（J≈1.5e-4 kg·m²、dt=10ms → 上限约 6）
- 所以** MuJoCo 的 kp=998 抄到 Gazebo 会立刻发散**——不是数不对，是承载这个数的积分方式不同

### 3.4 参数来源

Gazebo 版 = URDF 直接 spawn + 默认物理（未标定）；MuJoCo 版 = LeKiwi 官方真机对标调定（kp/kv/摩擦/限幅）。

### 3.5 一句话总结

**Gazebo 版是"传送带上的模型"（位置被硬摆过去），MuJoCo 版是"装真舵机的模型"（靠伺服力矩和重力博弈）**。看动画、学 ROS 两者皆可；做接触/抓取/力控仿真应选 MuJoCo，或给 Gazebo 配 effort 接口 + 高控制频率。
